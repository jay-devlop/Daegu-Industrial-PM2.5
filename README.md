# 대구 초미세먼지 관리 웹

기상조건에 따른 대구 산업단지 인접·비인접 지역의 초미세먼지(PM2.5) 농도 비교 분석 결과를 직접 살펴볼 수 있게 만든 웹사이트입니다.
*2026 대구광역시 기후·환경·탄소중립 공공 데이터 AI 활용대회* 출품작의 보고서 「기상조건에 따른 대구 산업단지 인접·비인접 지역의 초미세먼지 농도 비교」와 함께 제작했습니다.

## 만든 이유

대구 제3공단 근처 학교에 다니면서 공단 주변의 대기질에 관심을 갖게 되었습니다. 날씨에 따라 산업단지에 가까운 곳과 먼 곳의 초미세먼지 농도가 어떻게 다른지 알아보고, 그 결과를 누구나 시각별로 확인할 수 있도록 웹으로 만들었습니다.

## 주요 기능

| 탭 | 내용 |
| --- | --- |
| 지도 | 도시대기 측정소 19곳의 PM2.5 농도를 농도 구간별 색으로 표시하고, 산업단지 경계를 함께 보여줍니다. 농도가 높은 측정소 순위와 인접·비인접 그룹의 중앙값 차이, 같은 시각의 날씨를 확인할 수 있습니다. |
| 측정소 | 선택한 측정소의 선택 시각 전후 24시간 농도 변화를 비인접 그룹 중앙값과 비교합니다. 가장 가까운 산업단지, 기온·습도·강수량·풍속·풍향·전운량도 볼 수 있습니다. |
| 점검 | 농도를 확인한 뒤 점검 대상으로 등록하고 상태와 메모를 남깁니다. 기록은 이 브라우저(localStorage)에만 저장되는 가상 기록이며, CSV로 내려받을 수 있습니다. |

- 날짜와 시간을 골라 2023~2025년 어느 시각이든 조회할 수 있습니다.
- **약풍**, **여름 아침**, **격차가 큰 시간** 버튼으로 보고서의 분석 상황을 바로 볼 수 있습니다.
- 키보드와 스크린리더로 쓸 수 있도록 탭, 차트, 지도 마커에 접근성 속성을 넣었습니다.

## 분석 개요

- **기간**: 2023.01.01 01시 ~ 2025.12.31 23시 (26,303시간)
- **대상**: 대구 도시대기 측정소 19곳
  - 산업단지 경계로부터 2km 이내 9곳 (인접)
  - 2km 초과 10곳 (비인접)
- **비교 방법**: 매 시각 두 그룹의 PM2.5 중앙값을 구하고, 인접 값에서 비인접 값을 뺀 차이를 같은 시각의 기상자료와 연결했습니다. 두 그룹 모두 유효 측정소가 5곳 이상일 때만 비교합니다.
- **결측 처리**: 이상값과 기상 품질검사 오류값은 결측으로 처리했고, 0으로 바꾸지 않았습니다.

## 해석할 때 주의할 점

- 기상정보는 대구 ASOS 143 관측소 한 곳의 값입니다. 개별 대기 측정소에서 관측한 날씨가 아닙니다.
- 인접 2km는 분석을 위한 분류이며 공식 영향권이 아닙니다.
- 농도 차이만으로 오염원을 특정할 수 없습니다.
- 강수량 빈칸은 미관측과 무강수를 구분하지 않고 '자료 없음'으로 표시합니다. 풍향 0은 정온으로 표시합니다.
- 관측 기간(2023~2025)과 산업단지 경계 자료의 시점이 다릅니다.

## 실행 방법

빌드 과정이 필요 없는 정적 사이트입니다. `dist` 폴더를 웹 서버로 열면 됩니다.

```bash
cd dist
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. 배경지도는 OpenStreetMap 타일을 불러오며, 연결되지 않으면 측정소와 산업단지만 표시하는 지도로 대체됩니다.

## 폴더 구조

```text
.
├── dist/                    배포용 정적 사이트
│   ├── index.html
│   ├── app.js               화면과 기능
│   ├── style.css
│   └── assets/
│       ├── data-2023.json   연도별 시간별 농도·기상 자료
│       ├── data-2024.json
│       ├── data-2025.json
│       ├── stations.json    측정소 19곳 (좌표, 인접 여부, 가장 가까운 산업단지)
│       ├── parks.json       산업단지 경계 (GeoJSON)
│       └── leaflet.*        지도 라이브러리
└── scripts/
    ├── prepare_data.py      원본 CSV를 dist/assets의 JSON으로 변환
    └── add_park_names.py    측정소별 가장 가까운 산업단지 이름 추가
```

## 데이터 다시 만들기

`dist/assets`의 JSON은 이미 만들어져 있어 보통은 필요하지 않습니다. 원본 CSV에서 다시 만들려면 다음을 실행합니다.

```bash
# 원본 CSV 폴더가 기본 위치(프로젝트 폴더 옆 stage/)가 아니면 지정합니다.
export DAEGU_STAGE_DIR=/path/to/stage
python3 scripts/prepare_data.py
python3 scripts/add_park_names.py
```

`prepare_data.py`는 상위 폴더의 `산업단지 인접·비인접 분석/` 안의 CSV와 산업단지 GeoJSON(`*24곳_한글.geojson`)도 읽습니다. 산업단지 자료의 검색 위치는 `DAEGU_PROJECT_DIR`로 바꿀 수 있습니다.
